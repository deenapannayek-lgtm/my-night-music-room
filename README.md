# My Night — Music Room

A cozy, single-page music room for playing your own local tracks with a playlist and night-to-dawn ambience.

**[Open the live music room](https://deenapannayek-lgtm.github.io/my-night-music-room/)**

## Features

- Add multiple audio files from your device
- Play, pause, skip tracks, and seek through the current track
- Adjust volume and browse the current playlist
- Switch the scene between night and dawn
- Responsive layout for desktop and mobile

Music files are selected from your device in the browser. The site does not upload them to a server.

## Run locally

Open `index.html` in a modern browser, or serve the repository with any static web server. There is no build step or dependency installation.

## Built with

HTML, CSS, and vanilla JavaScript. Hosted with GitHub Pages.
